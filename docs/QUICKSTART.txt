IRA RATIONIS | VINDEX | Windows x64

1. Extract the entire irx-win-x64.zip into one directory.
2. Keep irx.exe, irx-native.dll, and the other packaged files together.
3. Open PowerShell there and run .\irx.exe --help.
4. Launch .\irx.exe or use .\irx.exe run to select a trusted executable.

No .NET SDK is needed to run the self-contained package. A successful build
does not establish working game startup, audio, account selection, or gameplay.

For independent playback of the packaged original Vindex media fixture:

    .\irx.exe media-probe --mf .\media\vindex-intro.mp4 --play

This uses Windows Media Foundation and requires installed H.264/AAC codecs.
Use --gpu instead of --play to exercise the D3D12 presenter. Neither mode
establishes the game's own media bindings. A separately installed trusted
FFmpeg executable can also be used:

    .\irx.exe media-probe <ffmpeg.exe> <local-clip.mp4> --stream-gpu

For process-scoped DNS and socket diagnostics, use a separate elevated terminal:

    .\irx.exe network-trace <game-process-id> <new-output.etl> 60

See docs/DIAGNOSTICS.md for scope, interpretation, and export instructions.
Keep matching EXE, DLL, and PDB files from a local publish when profiling;
the normal binary distribution excludes PDB files.

IRX is experimental and is not a sandbox; execute only trusted, authorized files.
Review README.md and the license texts. No commercial game files are bundled.
